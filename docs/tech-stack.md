# Tech Stack

> Portfolio knowledge source. Tools Frederick Aurelio Halim uses.

## 1. At a glance
<!-- rag-section: at-a-glance -->
Frederick Aurelio Halim works in TypeScript and JavaScript across the stack: React and Next.js on the frontend, Node.js with Express or NestJS on the backend, PostgreSQL or MongoDB for data, Redis and Socket.IO when the work is real-time, and Docker Compose, Nginx, GitHub Actions, or Vercel to ship.

- **Languages:** TypeScript, JavaScript, HTML, CSS.
- **Frontend:** React, Next.js, Vite, React Router, TanStack Query, Zustand, Tailwind CSS, React Hook Form, Zod.
- **Backend:** Node.js, Express, NestJS, Prisma, MongoDB, PostgreSQL, Redis, Socket.IO.
- **Infra:** Docker Compose, Nginx, GitHub Actions, Vercel.

## 2. Languages
<!-- rag-section: languages -->
- **TypeScript** — main language for app and API work.
- **JavaScript** — same runtime; TS compiles to it.
- **HTML, CSS** — page structure and layout, usually with Tailwind CSS.

## 3. Frontend
<!-- rag-section: frontend -->
- **React** — UI library across jobs and projects.
- **Next.js** — App Router apps (Memories, Nextjs-FXTrade, Promis, this portfolio).
- **Vite** — SPA builds (Cabin PMS staff UI, Mufy, QuizConnect).
- **React Router** — client routing on Vite SPAs (Mufy, QuizConnect).
- **TanStack Query** — server state and data fetching.
- **Zustand** — client state on Mufy.
- **Tailwind CSS** — styling.
- **React Hook Form, Zod** — forms and validation (Mufy, Cabin PMS, QuizConnect).

## 4. Backend
<!-- rag-section: backend -->
- **Node.js** — runtime for Express and NestJS.
- **Express** — REST APIs (QuizConnect, Memories).
- **NestJS** — REST API for Cabin PMS.
- **Prisma** — ORM on Cabin PMS with PostgreSQL.
- **PostgreSQL** — Cabin PMS; also Supabase Postgres on Nextjs-FXTrade.
- **MongoDB** — QuizConnect and Memories.
- **Redis** — QuizConnect (lobby state, BullMQ).
- **Socket.IO** — QuizConnect live rooms.

## 5. Infra
<!-- rag-section: infra -->
- **Docker Compose** — app + Redis/Postgres/Mongo/Nginx on VPS deploys.
- **Nginx** — reverse proxy in front of those stacks.
- **GitHub Actions** — CI/CD, SSH deploy to VPS.
- **Vercel** — Next.js deploys (Nextjs-FXTrade, Promis, this portfolio's international site).
